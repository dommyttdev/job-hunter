# 運用

本番環境でシステムを安全かつ継続的に稼働させるための情報を配置します。

## 追加予定の文書

- `configuration.md` — 環境別設定とシークレットの管理
- `observability.md` — ログ、メトリクス、アラート
- `runbook.md` — 日常運用と障害対応
- `security.md` — 認証情報、アクセス制御、脆弱性対応
- `data-retention.md` — 現在版・直前版、処理中イベント、ログの保持と削除
- `backup-and-recovery.md` — バックアップと復旧手順
- `source-circuit-breaker.md` — サイト障害中・取得不可の判定、再基準化、再開
- `codex-usage.md` — 1回・日次・月次上限、巨大入力の分割、フォールバック監視
