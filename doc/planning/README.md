# 計画

JobHunterの要件と設計を、段階、実装順序、着手可能な作業へ変換する文書を配置します。

## 現行段階

- MVP: 計画準備中

## 文書一覧

- [段階別計画](./stages/README.md) — 現行段階と完了済み段階の索引

## 運用ルール

- 要件と設計は既存文書を正本とし、計画文書へ複製しない。
- バックログカードは段階に所属させる。
- 状態は文書内の永続状態で管理し、状態別ディレクトリを作らない。
- サブタスクは独立して実装、検証、コミットできる場合だけ作る。
- 詳細な書式は[計画文書フォーマット](../development/documentation-formats/planning.md)に従う。
