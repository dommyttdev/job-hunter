# 計画文書テンプレート

段階バックログへ新しい親カードまたはサブタスクを追加するときに使うテンプレートです。

## テンプレート一覧

- [親バックログカード](./backlog-card.md) — 目的、状態、受入境界を定義する
- [バックログサブタスク](./backlog-subtask.md) — 独立して実装・検証・コミットできる作業を定義する

## 使用手順

1. 親カードは段階の`backlog/<card-id>/README.md`へコピーする。
2. カードID、状態、依存、根拠を段階のバックログ索引へ追加する。
3. 要件や設計を複製せず、確定済み仕様には作業境界に必要な要約と正本文書へのリンクを書く。
4. 依存と停止条件を含めて単独着手できる場合だけ`Ready`にする。
5. サブタスクは親カードが`Ready`で、成果を独立コミットできる場合だけ作る。
6. 不要な見出しは削除せず、該当しない理由を記載する。

## 命名

- 親カード: `<STAGE>-<AREA>-<NNN>`、ディレクトリは小文字化する。
- サブタスクID: `<CARD-ID>-ST<NN>`。
- サブタスクファイル: `<card-id>-st<nn>-<short-name>.md`。
