# MVP-SOURCE-001: 求人を安全に取得する

- 状態: Current
- カード状態: Planned
- バックログ索引: [MVPバックログ](../README.md)

## 目的

対応サイトの検索結果を最後まで巡回し、求人ID、正規URL、タイトル、求人固有canonical HTMLを共通処理へ渡せる取得経路を作る。

## Ready判定

- `MVP-FOUND-001`が`Accepted`である。
- 最初に実装するサイトの取得許可、検索方式、安全上限、契約HTMLが確定している。
- サイト固有文書に未決事項が残っていない。

## Accepted判定

- 共通契約と最初のサイトアダプターを明示登録できる。
- 全検索ページの成功時だけ結果を確定し、途中失敗と安全上限到達時は部分結果を破棄する。
- 詳細ページを5分類し、タイトルと求人固有canonical HTMLを抽出できる。
- サイト別レート制限、タイムアウト、再試行、SSRF対策がテストされている。

## 確定済み仕様

- 求人は`source_key`と`external_job_id`で識別する。
- 検索結果は利用者向け発見にだけ使い、一覧からの消失を掲載終了に使わない。
- 詳細結果は`AVAILABLE`、`NOT_FOUND`、`REMOVED`、`RETRYABLE_ERROR`、`UNEXPECTED`へ分類する。
- タイトルと求人固有領域の両方を抽出できない限り、版を保存しない。
- ページ全体の生HTMLを保存せず、allowlistで抽出・正規化したHTMLを渡す。

## 受入条件

- 通常リンク、form、無限スクロールのうち対象サイトが採用する方式をfixtureで終端まで巡回できる。
- 重複リンクを1求人へ集約し、URLを許可されたscheme、host、pathへ正規化できる。
- 200応答の掲載終了ページを明示マーカーで`REMOVED`と判定できる。
- 401、403、429、5xx、通信失敗、解析失敗を掲載終了として返さない。
- selector不一致、タイトル欠落、安全上限到達が安全側へ失敗する。

## 対象外

- 取得結果に基づく求人状態遷移と通知
- ログイン必須サイト、未確認サイト、サイト間の求人名寄せ
- ブラウザー方式を使わないサイトへのブラウザー依存導入

## 停止条件

- 取得許可を確認できない、または認証なしで取得できない。
- 安定した求人ID、求人固有領域、掲載終了マーカーをfixtureから特定できない。
- サイト仕様が安全上限内で完全巡回できない。

## サブタスク構成

依存解消後、共通契約、HTTP・ブラウザー境界、最初のサイト実装、契約テストが独立してコミット可能かを精査してから分割する。
