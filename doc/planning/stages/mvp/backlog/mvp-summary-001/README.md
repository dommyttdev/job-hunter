# MVP-SUMMARY-001: 求人要約を生成する

- 状態: Current
- カード状態: Planned
- バックログ索引: [MVPバックログ](../README.md)

## 目的

求人の現在版と通知対象差分を安全にCodex CLIへ渡し、利用可能な要約または決定的なフォールバックを確定する。

## Ready判定

- `MVP-DETECT-001`が`Accepted`である。
- Codex CLIの呼び出し契約、実行環境、設定可能な上限の単位を固定できる。
- canonical HTMLを不信入力として隔離するプロンプト境界をテストできる。

## Accepted判定

- 現在要約を求人版ごとに1件生成し、利用者間で共有できる。
- 変更要約を最後に通知した版と最新の版から求人単位に生成できる。
- 入出力、時間、日次・月次上限と長文分割を強制できる。
- 最終失敗または上限到達時にタイトルとURLを返し、後続処理を停止しない。

## 確定済み仕様

- 現在要約はLINE通知のON・OFFにかかわらず生成する。
- LINE通知がOFFの利用者には変更要約を生成しない。
- 更新要約は前回版固定ではなく、利用者へ最後に通知した版と最新の版を比較する。
- HTML中の命令をシステム命令として扱わず、出力を表示・通知用データとして検証する。
- 大きなHTMLは見出し・項目単位で決定的に分割し、上限超過時はフォールバックする。

## 受入条件

- 同じ版・同じ通知項目の再処理で要約結果と作業を重複させない。
- CLI成功、タイムアウト、不正出力、非ゼロ終了、利用枠到達、分割上限到達をテストできる。
- 失敗時結果に機械抽出した求人タイトルと求人URLが含まれる。
- canonical HTML、CLI入出力、secretを通常ログへ出さない。
- 要約失敗が変更イベントと求人版の有効性へ影響しない。

## 対象外

- 求人内容の恒久的な項目別構造化、利用者別の現在要約、過去要約履歴
- Codex CLI以外の生成AIプロバイダー、品質評価用の管理画面

## 停止条件

- CLIの非対話実行と入力隔離を保証できない。
- 利用量を上限判定できる安定した計測単位がない。
- 出力検証に必要な通知表示契約が未確定である。

## サブタスク構成

依存解消後、CLI境界、現在要約、変更要約、利用制限・フォールバックを独立して検証できる単位へ分割する。
