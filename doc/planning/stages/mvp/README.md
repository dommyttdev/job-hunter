# MVP計画

- 状態: Current

## 目的

利用者が検索結果URLを登録し、求人の発見・更新・掲載終了をWebで確認し、任意でLINEの定期ダイジェストを受け取れる最小の運用可能なシステムを完成させる。

## 開始条件

- プロダクト要件、システム設計、主要ADRがレビュー可能な状態である。
- MVPの対象範囲と実装順序が合意されている。

## 完了条件

- [MVP機能範囲](./scope.md)の完了条件を満たす。
- 全バックログカードが`Accepted`である。
- 対応サイトごとの取得許可確認と運用手順が記録されている。
