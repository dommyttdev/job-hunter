# 完了済み段階

完了判定後の段階計画を、当時の範囲、優先順位、バックログとともに保存します。

## アーカイブ済み段階

なし。

## 移動条件

- 段階の完了条件を満たしている。
- 段階内の全親カードが`Accepted`である。
- 未完了の作業を次段階のバックログへ移管している。
- 要件、設計、運用文書が最終実装と一致している。
- 段階READMEの状態を`Completed`にしたコミットが存在する。

## 移動方法

1. `stages/<stage>/`全体を`stages/archive/<stage>/`へ移す。
2. 移動した段階READMEの状態を`Archived`へ変更する。
3. [段階別計画](../README.md)の現行段階と完了済み段階を更新する。
4. [製品ロードマップ](../../roadmap.md)の段階状態と移行条件を更新する。
5. 相対リンクを検証し、リンク切れを修正する。

個別カードだけをアーカイブへ移さない。`Accepted`カードは段階の作業記録として現行段階内に残す。
