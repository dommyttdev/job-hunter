# 通知

検知した求人の変更を、必要な相手へ過不足なく届けるための仕様を定義します。

## 文書

- `channels.md` — 対応する通知先とチャネルごとの制約
- `routing-rules.md` — 通知対象、条件、宛先の決定方法
- `delivery-policy.md` — 即時・ダイジェスト、再試行、重複通知の抑制
- `message-format.md` — 新着・更新・削除ごとのメッセージ形式
- `failure-handling.md` — 配信失敗、再送、デッドレターの扱い
- [求人変更通知](./job-change-notifications.md) — 要約、通知内容、重複抑制、失敗処理
