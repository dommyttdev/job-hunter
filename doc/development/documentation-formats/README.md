## 共通規則

- Markdownを基本とし、状態値は各フォーマットに従う。
- 判定・対応関係は表、複雑な関係・遷移はMermaidで表す。
- 更新日、更新者、変更履歴はGitと重複するため記載しない。
- 空の見出し、自明な説明、本文と重複する要約を置かない。
