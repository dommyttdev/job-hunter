# 変更検知

取得した求人を直前の状態と比較し、利用者向け発見・更新・削除を判定する規則を定義します。

## 文書

- `job-identity.md` — 求人の同一性判定と重複排除
- [求人変更の判定](./change-rules.md) — 利用者向け発見・更新・削除・再掲載の定義と判定規則
- `lifecycle.md` — 求人状態の遷移、再掲載、取得失敗時の扱い
- `event-schema.md` — 変更イベントのデータ形式
- `edge-cases.md` — URL変更、表記揺れ、一時的な掲載停止などの例外
